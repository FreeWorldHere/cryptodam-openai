A little clarity

Before your first conversation.

Why can’t I find it in ChatGPT’s directory yet?

A public listing requires OpenAI’s verification, review, and publication process. Website or GitHub availability does not create a listing. This page will use the real directory link only after one exists.

Will it include all of my watchlist and older alerts?

The core briefing covers the records returned by the connected tools. The reviewed source limits responses to up to 200 joined watchlist items and 100 non-archived alerts. It is not a full-history export or proof that a notification was delivered. Hosted behavior may differ and still needs review.

Can I use another member’s private information?

No permission to do so is provided by this package. The connection uses the signed-in account’s existing authorization. It provides no user selector, service key, or permission bypass.

Does the package control every tool on the server?

No. Skills describe workflows; they do not hide or disable other tools on the shared MCP server. Actual server tools and permissions must be reviewed in the connection or portal. The core package does not activate optional providers.

Where can I get help or disconnect?

Use CryptoDam’s existing connected-application controls and your ChatGPT account or workspace’s connection controls. For support, open the contact page or email stuporeinvestment.kj@gmail.com. Never include credentials or private financial records in a support request.
